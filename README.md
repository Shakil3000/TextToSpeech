\# TextToSpeech



An Android application that converts typed text into spoken audio using Android's built-in Text-to-Speech engine.



\## Features



\- Enter any text and listen to it as speech

\- Simple and easy-to-use interface

\- Works on Android devices



\## Tech Stack



\- Language: Java

\- Platform: Android

\- Build Tool: Gradle

\- IDE: Android Studio



\## How to Run



1\. Clone the repository:

&#x20;  git clone https://github.com/Shakil3000/TextToSpeech.git

2\. Open the project in Android Studio

3\. Wait for Gradle sync to finish

4\. Run the app on an emulator or a real Android device
